# Raspberry Pi Programming Assignment

This repository contains coursework and assignments for the **Coursera Raspberry Pi course**. It includes Python scripts, configuration files, and documentation related to Raspberry Pi hardware and software projects.

## 📘 Course Overview

The course provides an introduction to the Raspberry Pi platform, exploring its hardware, operating system, and use in IoT and embedded systems. Assignments focus on practical applications using GPIO pins, sensors, and programming with Python.


## 🛠 Requirements

- Raspberry Pi (any model with GPIO support)
- Raspbian OS (or Raspberry Pi OS)
- Python 3
- GPIO libraries (e.g., `RPi.GPIO`, `gpiozero`)
- Basic electronic components (LEDs, resistors, sensors, etc.)
